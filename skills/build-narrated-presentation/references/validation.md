# 验收与失败处理

## 自动验收

在生成任何 SVG 前先确认：

1. 输入自动预检没有阻断项；
2. 语义复核与当前文档 SHA-256 一致；
3. 所有语义维度和总决策均为 `pass`；
4. `init --input-document` 成功。

输入门禁未通过时，完成定义是“已输出可执行返工报告并停止”，不是继续制作占位页面。

在生成完整 PPTX 前依次检查：

1. 静态 SVG 可独立查看，尺寸、文字、截图和事实正确。
2. 分层叠加与源 SVG 像素一致。
3. 首秒动画时间轴与视觉 manifest 一致。
4. 每页只有一份导演稿、一段连续 SSML 和一个 MP3。
5. 音频时间轴来自实际 MP3。
6. PPTX 中 SVG、图片和音频都为内部关系。
7. `mediacall`、自动换页和演示级属性正确。
8. PPTX 可由 `python-pptx` 只读回读。
9. 先对三类样板页通过同样检查，再生成整套。

编辑阶段可以运行普通项目校验并保留尚无音频时间轴等警告；进入 PPTX 装配前必须使用 `validate --strict`。普通校验通过只代表当前已有契约一致，不代表旁白、PPTX 或 MP4 已完成。

## PowerPoint 实机验收

从第一页完整播放并确认：

- 打开时没有“发现问题并修复”；
- 编辑视图显示正常音频图标，不是黑块；
- 入页立即自动播放声音；
- 全程无需点击；
- 动画在一秒内完成；
- 音频开头不丢字、结尾不截断；
- 音频结束后自然换页；
- SVG 和截图清晰；
- 最后一页结束后不循环；
- 总时长符合要求。

## MP4 验收

- 画面分辨率符合交付要求；
- 开头、过渡、截图页和结尾没有黑帧或跳变；
- 音画完整，无截断、重复或静音页；
- MP4 总时长与 PPTX 真实预计时长接近；
- 抽查所有页面边界，确认没有提前换页。

## 常见失败

| 表现 | 原因 | 处理 |
|---|---|---|
| 动画拖沓 | 按旁白逐句排动画 | 解耦三套时钟，首秒完成 |
| 旁白机械讲图 | 每层绑定一句 | 每页连续口述，先讲判断 |
| 没声音 | 只嵌入媒体 | 写入原生 `mediacall` |
| 音频图标黑块 | poster 无效或全透明 | 使用正常扬声器图片 |
| 页面过早切换 | 使用估算时长 | 读取 MP3 实际时长并加 150ms |
| 总时长失控 | 先写死页时长 | 先合成音频，再改文案 |
| 截图模糊 | 过度缩小或压扁 | 减少同页截图并保持比例 |
| 图层错位 | 局部裁切拼装 | 使用完整画布图层 |
| PowerPoint 修复文件 | OOXML 节点、关系或顺序错误 | 校验包结构与 XML 顺序 |
| 离线无声音 | MP3 是外部链接 | 内嵌到 `ppt/media/` |
| 旧版影响构建 | 多套 manifest 并列 | 当前工作目录只保留生效版本 |

## 完成定义

只有以下条件同时满足才算完成：

- 输入文档通过自动预检和语义复核；
- 静态 SVG 本身成立；
- 分层叠加与原图一致；
- 动画在首秒完成；
- 每页只有一段连续旁白；
- 页面时长来自真实 MP3；
- 所有媒体内嵌；
- PowerPoint 不修复；
- 全程自动播放和换页；
- 最后一页不循环；
- Windows PowerPoint 成功导出；
- MP4 清晰、声音完整、时长符合要求。
