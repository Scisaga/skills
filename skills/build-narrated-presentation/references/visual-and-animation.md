# SVG 与动画

## 静态页先行

动画制作前，让每页 SVG 单独打开就能提交：

- 统一 16:9，默认 `1600×900`；
- 标题、正文、截图和图形不溢出；
- 箭头首尾真正连接，尺寸不过分抢眼；
- 截图保持可读比例，标签放在截图外；
- 页面事实、术语和产品立场已确认；
- 字体、外部图片和样式可被确定性解析。

动画不能修复静态页面的排版或事实问题。

## 单页设计改稿

只调整指定页 SVG 且不要求同步 PPTX、动画或视频时，直接编辑该页的 `source_svg`，不要启动项目初始化、审批、装配或整套 QA。读取范围限制为目标页内容、当前模板安全区和已选视觉规范；不得顺带统一其他页面、改写口述稿或重做音频。

交付前只对目标 SVG 做局部检查：

1. XML 可解析，根元素为 SVG，`viewBox` 为 `0 0 1600 900`；
2. 字体、图片、滤镜和样式可确定性解析，不保留远程或机器绝对路径引用；
3. 主体位于模板安全区内，没有裁切、遮挡、溢出或重复模板标题、Logo、页脚；
4. 以 1600×900 渲染后目视检查排版、连线、截图、事实和术语；
5. 再以 400×225 缩略图检查层级、字号、密度和主要关系是否仍可辨认。

局部检查只证明目标 SVG 可交付，不更新 `build_state.json`，也不等同于 static 或 standard QA。交付时列出改动页，并明确 PPTX、动画和视频是否未同步。

## 模板与 SVG 分工

PowerPoint 模板层负责背景、封面、标题、副标题、Logo、页脚、页码和内容安全区。用户模板原件保持不变，适配结果另存为 `template.pptx`。

主体 SVG 仍使用完整 `1600×900` 透明画布并插入 `(0, 0)`，但只在 `project.json.template.safe_area` 内绘制主体。不要在 SVG 中重复模板标题、Logo 或页脚，也不要用遮罩覆盖模板旧元素。

模板完成后选择 1–4 张高风险页面制作代表性样稿。确认模板、字号、密度、截图比例、图标和连线后执行视觉审批，再批量制作全稿。

## 风格选择

`project.json.visual.style_preset` 支持：

- `project-default`：遵循项目已有品牌和视觉系统；
- `technical-infographic`：使用原创的现代技术信息图语言，适合系统流程、架构、对比、分类和故障链路。

`theme` 支持 `light` 与 `dark`，`density` 固定为 `presentation`。风格只改变视觉表达，不改变输入事实、旁白或页面顺序。切换风格后必须重新生成并验收 SVG，不能使用 `rebuild --scope audio`。

选择 `technical-infographic` 时，读取 `technical-infographic-style.md`。先完成一张能代表全套质量的样板页，确认字号、密度、图标和连线后再批量制作。

## 全画布分层

所有分层 SVG 使用源页完整画布并叠放到 PPT 的 `(0, 0)`：

| 图层 | 内容 | 动画 |
|---|---|---|
| `base` | 安全区内的固定连线、装饰和容器 | 无 |
| `title` | SVG 主体中的局部标题和状态标签 | `fade` |
| `beat_*` | 面板、截图、流程、结论 | `fade` 或方向性 `wipe` |

不要裁成局部 SVG 再靠坐标拼装。局部裁切会引入坐标、缩放、描边、图片裁切和 PowerPoint 渲染差异。

## 动画规则

稳定支持：

- `fade`：标题、截图和结论；
- `wipe_left` / `wipe_right`：横向流程；
- `wipe_up` / `wipe_down`：纵向步骤。

不要使用退出动画、弹跳、旋转、大幅缩放、复杂运动路径或逐句排队。截图只淡入。每页最多六个动画组。

装入 PPTX 后，每个动画组的对象名固定为 `sNN_<beat_id>`，例如第 1 页 `title` 为 `s01_title`、`beat_01` 为 `s01_beat_01`。该名称是 static QA 从 OOXML 的 shape target 反查 manifest beat 的机器契约，不是可随意修改的显示标签。

技术信息图页允许用依次淡入或方向性 wipe 表达结构建立和流程推进；不要照搬社交平台 GIF 的循环脉冲、发光和旋转加载效果。视频中的信息关系必须在动画停止后仍完整可读。

默认并行动画：

```text
旁白开始       0ms
标题开始       0ms
第一内容组     120ms
后续组间隔     130ms
单组持续       280ms
全部完成       500–1000ms
```

动画的作用是迅速建立页面，不承担逐句解释。

## 分层验证

进入 PPTX 装配前：

1. 校验源 SVG SHA-256；
2. 确认每层自包含，外部图片已内联；
3. 按顺序叠加全部层；
4. 把叠加结果与源 SVG 按同尺寸渲染；
5. 比较平均像素误差和显著差异像素比例；
6. 输出机器可读和可读报告。

视觉差异未通过时，停止 PPTX 装配。
