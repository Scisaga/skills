# SVG 与动画

## 静态页先行

动画制作前，让每页 SVG 单独打开就能提交：

- 统一 16:9，默认 `1600×900`；
- 标题、正文、截图和图形不溢出；
- 箭头首尾真正连接，尺寸不过分抢眼；
- 截图保持可读比例，标签放在截图外；
- 页面事实、术语和产品立场已确认；
- 字体、外部图片和样式可被确定性解析。

动画不能修复静态页面的排版或事实问题。

## 全画布分层

所有分层 SVG 使用源页完整画布并叠放到 PPT 的 `(0, 0)`：

| 图层 | 内容 | 动画 |
|---|---|---|
| `base` | 背景、装饰、固定边框、页脚 | 无 |
| `title` | 栏目、标题、副标题、状态标签 | `fade` |
| `beat_*` | 面板、截图、流程、结论 | `fade` 或方向性 `wipe` |

不要裁成局部 SVG 再靠坐标拼装。局部裁切会引入坐标、缩放、描边、图片裁切和 PowerPoint 渲染差异。

## 动画规则

稳定支持：

- `fade`：标题、截图和结论；
- `wipe_left` / `wipe_right`：横向流程；
- `wipe_up` / `wipe_down`：纵向步骤。

不要使用退出动画、弹跳、旋转、大幅缩放、复杂运动路径或逐句排队。截图只淡入。每页最多六个动画组。

默认并行动画：

```text
旁白开始       0ms
标题开始       0ms
第一内容组     120ms
后续组间隔     130ms
单组持续       280ms
全部完成       500–1000ms
```

动画的作用是迅速建立页面，不承担逐句解释。

## 分层验证

进入 PPTX 装配前：

1. 校验源 SVG SHA-256；
2. 确认每层自包含，外部图片已内联；
3. 按顺序叠加全部层；
4. 把叠加结果与源 SVG 按同尺寸渲染；
5. 比较平均像素误差和显著差异像素比例；
6. 输出机器可读和可读报告。

视觉差异未通过时，停止 PPTX 装配。
