# 专业技术 PPT 图示参考

## 定位与适用范围

这三张图是专业技术类 PPT 的启发性示例，供需要解释对象结构、工作机理、工程流程或系统关系的页面参考。它们展示一种可以达到的表达水平，鼓励智能体思考当前内容怎样画得更具体、更清楚；不是固定模板或组件库，也不要求复制其构图、配色、业务对象或图形数量。

示例不规定其他类型 PPT 的视觉风格或复杂度。商务汇报、管理沟通、营销、教学等内容按各自受众与用途设计；专业技术 PPT 的封面、观点页、过渡页，以及无需展开内部机制的页面，也可以保持简洁。需要多少细节，由当前页面的解释任务决定。

先看 PNG 理解整体表达，必要时再读 SVG 了解绘制方式。PNG 用于观察，实际交付仍绘制适合当前内容的可编辑 SVG。

示例来自用户提供的三张 SVG，已去除右上角大赛标识和底部“航空工业”字样。其余业务文字、品牌、模型名称及页码属于示例上下文，不作为新项目的事实或内容。

## 可以从示例中思考什么

### 经验闭环

现场作业、过程记录、审核学习与发布回流构成一个有具体对象和状态变化的过程。

- 工件轮廓、设备支撑、屏幕和仪表等细节，为什么能帮助识别作业场景？
- 图谱、状态流与过程记录分别解释了什么，怎样让“经验积累”这样的抽象概念变得具体？
- 审核与学习为什么分支表达，反馈回路又如何保持清楚？

### 平台架构

外围输入、基础能力、中央平台、现场终端与应用结果具有不同层级，内部子图说明各部分如何工作。

- 位置、大小、边界和留白怎样区分整体系统、子系统与局部细节？
- 图谱、状态流、模型网络与验证趋势为什么采用不同表达？
- 输入、输出与反馈怎样建立阅读顺序，连线如何与标签错开？

### 经济价值

不同价值来源按共同维度并列，具体业务图形、指标与说明形成可比较的层次，整体价值关系另作强调。

- 不同插画怎样表达不同业务动作，同时保持相近的视觉重量？
- 标题、指标、说明怎样通过对齐和留白形成秩序？
- 公式与价值链怎样突出整体关系，而不与各列内容争夺注意力？

## 用于当前任务

根据实际内容，思考哪些对象、过程或关系值得画出来，哪些细节能帮助理解，以及怎样安排主次和阅读顺序。再自主选择图形与构图；可以采用示例之外的新形式，也可以用更简洁的表达完成解释。

细节的价值在于说明内容，不能用增加图元数量或堆满画面来代替设计。示例仅帮助打开思路，不增加固定的绘图步骤、审批层或逐页确认。

实际制作仍遵守项目的品牌、事实、页序和模板安全区，并按 `visual-and-animation.md` 检查全尺寸与缩略图：前者检查细节、文字与连线，后者检查主次和阅读方向。
