# 验收和完成条件

## 审批与输入

| 操作 | 必需审批 |
|---|---|
| 制作内容派生、导演稿或代表页 | content |
| 组装或验收静态、动画 HTML | content、visual |
| 旁白合成和 audio QA | content、narration |
| 组装和验收带旁白 HTML | content、visual、narration |

`approve` 依据当前输入写入状态，内容、字体、代表页或声音等变动会使对应摘要失效。`validate --strict` 会将警告计为失败。诊断通过与生产验收分别记录。纯音频链可独立运行。

## QA 等级

- `qa --level audio` 核对逐页讲稿和导演稿、可执行韵律、最终 `±0.1st` 音高、读法覆盖、实际音频服务、章节缓存、切分摘要、MP3 文件和时长。未覆盖术语和时长差异按报告审阅。真实音色和发音可用试听确认。
- `qa --level static` 打开当前离线包，验证资源和嵌入字体、SVG 渲染、画布和浏览器动画前、中、后状态。报告记录渲染摘要和字体替换。
- `qa --level standard` 绑定当前 static、audio 报告，并核对旁白时长及实际页面切换。带旁白的 HTML 和视频以此为验收前置。

每个报告写在 `video/qa_<level>.json`。缓存命中须同时满足检查依赖、当前产物摘要、报告实际内容和运行状态。`--force` 可重检。网页包、ZIP 或输入资源变化后重新组装，审批按受影响的内容重新确认。

## 导出和局部检查

PDF、PNG 和 JPG 在当前 static QA 通过后生成。MP4 导出后验证流、帧数、画面尺寸、帧率、色彩和音画时长，记录 `video/video_export.json`。如还要检查实际演讲节奏，可对照浏览器播放和 MP4 关键帧。

局部 SVG 改稿查看目标页的全尺寸与缩略图，报告所改页面。整套产物的状态由正式组装和验收更新。
