# 字幕匹配规则

## 候选优先级

1. 已经在视频同目录并符合自动加载命名的中文字幕。
2. 同目录或 `Subs/`、`subs/` 子目录中的中文字幕，可复制/归一化到自动加载命名。
3. ASSRT 中片名、年份、集数、版本名高度匹配的候选。
4. SubHD 中片名、年份、完整文件名、版本 token 和质量标记匹配的候选。
5. 只有片名匹配但版本不清楚的候选，必须下载后强校验；不能直接采用。

## 标题与集数

- 电影至少匹配英文片名或常见中文译名，并尽量匹配年份。
- 剧集必须匹配季集号，例如 `S03E01`、`3x01`、`Season 1 Episode 1`。
- 搜索结果若明显是另一部片或另一年，直接拒绝。
- 片名短、重名多、系列片多的项目要提高年份和版本 token 权重。

## 版本 token

优先比较以下 token：

```text
webdl webrip bluray uhd hdtv hmax amzn nf dsnp atvp
h264 h265 x264 x265 hevc avc hdr hdr10plus dv
ddp5 dd5 eac3 atmos truehd dts 1080p 2160p 720p
smurf flux nogrp cm cmrg tepes naisu apex ntg fgt rarbg yts
```

完整文件名或主版本名命中时加高权重。只命中通用 token，例如 `1080p` 或 `BluRay`，不能单独作为高置信依据。

## 语言与字幕类型

- 优先 `chs`、简体、简英双语。
- 可接受 `cht`、繁体、繁英双语，报告里保留 `cht` 标记。
- 同等版本、同等质量、同等校验结果下，简体优先于繁体；不要让繁体仅因为也带“官方/精校/字幕组”标签而压过简体。
- 文件名没有简繁标记时，根据字幕正文的简繁特征字做弱判断，并把结果用于目标文件名和候选排序。
- 可接受官方字幕、原创翻译、转载精修、可信字幕组。
- 英文-only、非中文字幕、OCR 失败、机器翻译且无其他强证据的候选应拒绝。
- SUP/PGS 图片字幕只有在流程能转换或用户明确接受时才采用。

## 下载后校验

下载或解压后必须检查：

1. 是否存在 `.srt`、`.ass`、`.ssa`、`.vtt` 等有效字幕文件。
2. 是否可解码，优先 UTF-8，其次 GB18030、Big5、UTF-16。
3. 是否能解析出足够时间码；电影建议至少 80 条，短剧集可降低。
4. 是否含中文字符。
5. 末条字幕结束时间与视频时长差是否在阈值内。
6. 片头、片尾、字幕跨度和时间码分布是否合理。
7. 若视频内有英文或其他非中文文本字幕流，抽取该流作为时间轴锚点，比对中文字幕 cue 中点与原文 cue 中点的最近邻偏移。

默认时长阈值为视频时长的 2%，并限制在 30 到 180 秒之间。这个阈值只能用于“直接通过”，不能作为唯一拒绝标准。页面标注片源时长与视频时长高度匹配、完整文件名匹配、字幕组可信或官方字幕时，应把“最后对白早于片尾”的情况放入二阶段比对，而不是直接失败。

## 大片尾间隔

以下情况不可直接当作失败，应进入二阶段比对或人工抽查：

- 最后对白早于片尾 300 秒以上。
- 主要通过片源名、字幕组或页面时长通过，而非末条时间码直接通过。
- 候选版本与视频版本不完全一致，但片源家族、平台、编码和字幕组高度可信。

300 到 600 秒的大间隔通常是长片尾、字幕文件省略片尾字幕、版本片尾差异或错误字幕四种情况之一，必须通过二阶段比对区分。超过 600 秒的大间隔默认拒绝，除非标题、年份、版本和抽样比对仍强匹配。

## 二阶段队列

不要把以下项目直接归为 `not_completed`：

- 已下载中文候选，唯一问题是 `duration_mismatch` 或“最后时间码差”在 600 秒以内。
- 下载链接失败、签名失败、浏览器校验失败、SubHD API 500，但报告里有候选 URL。
- 候选被“机器翻译”过滤，但没有其他人工字幕，且标题/年份/版本强匹配。
- 解压失败或 `no_sub_files`，但来源页明确是 SRT/ASS 字幕。

这些项目分别放入 `needs_compare`、`retry_download`、`review_relaxed_filter` 或 `retry_extract`。

## 拒绝理由

常用拒绝理由：

```text
non_chinese
too_few_cues
duration_mismatch
wrong_title_or_year
wrong_episode
extract_or_no_subtitle_files
download_failed
api_failed
signature_or_browser_check_failed
machine_translation_only
low_confidence_candidate
```
