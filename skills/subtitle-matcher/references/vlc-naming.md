# VLC 自动加载命名

## 目标命名

字幕文件应与视频文件在同一目录，并使用完整视频 base name：

```text
Movie.Name.2022.1080p.WEB-DL.x264-GROUP.mkv
Movie.Name.2022.1080p.WEB-DL.x264-GROUP.chs.srt
Movie.Name.2022.1080p.WEB-DL.x264-GROUP.cht.ass
```

## 语言后缀

- `chs`：简体中文或简英双语。
- `cht`：繁体中文或繁英双语。
- `zh`：只有在无法判断简繁时使用；后续应尽量归一化为 `chs` 或 `cht`。

## 归一化规则

1. 如果目标命名已存在，不覆盖。
2. 如果同目录已有明显中文字幕，但命名不规范，可复制到目标命名。
3. 如果 `Subs/` 子目录里有中文字幕，可复制到视频同目录目标命名。
4. 多字幕文件同时存在时，优先简中、双语、官方、精校、版本名匹配者。
5. 不删除原字幕文件。

## 避免误配

- 不把英文-only 文件命名为 `.chs`。
- 不跨视频目录复制字幕，除非片名、年份、集数和版本明确匹配。
- 剧集目录中每集只匹配自己的 `SxxEyy`。
